# EU5 Urbanization Rebalance

Eigenständiges Modding-Projekt für Bevölkerungskapazität und Urbanisierung von Locations in **Europa Universalis V (EU5)**.

**Aktuelle Phase (2026-10-09):** Quellenaufbau / Portierungsvorbereitung für **EU5 1.4 Beta**. **Nicht als getestete, spielfertige Mod deklarieren.**

## Projektgrundlage

Die verbindlichen, im Repository versionierten Referenzen stehen in **[Docs/](Docs/README.md)**. Für Codex gilt zusätzlich [AGENTS.md](AGENTS.md).

- Quelle der Gameplay-Idee: [MEIOU & Taxes PR #271 „Feature/population“](https://github.com/MEIOU-and-Taxes/MnT-EU5/pull/271)
- 1.4-Beta-Script-Schnittstelle: [Community Modding Digests (1.4-beta)](https://github.com/Europa-Universalis-5-Modding-Co-op/modding-digests/tree/1.4-beta)
- Genau geprüfte SHA-Stände und extrahierte Werte: [Docs/SOURCES.md](Docs/SOURCES.md) und [Docs/MNT_POPULATION_REFERENCE.md](Docs/MNT_POPULATION_REFERENCE.md)
- Entwicklungs-/Prüfprozess: [Docs/CODEX_WORKFLOW.md](Docs/CODEX_WORKFLOW.md)

**Wichtig:** EU5 1.4 Beta ist patchabhängig. Technische Aussagen und `REPLACE`-Overrides müssen mit Vanilla-Dateien und Engine-Dumps der *tatsächlich verwendeten* Spielversion abgeglichen werden.

Dieses Repository soll die komplette eigenständige Mod und ihre Dokumentation enthalten, ohne MnT als erforderliche Spiel-Mod.
